# Japaccent.（ジャパクセント）

日本語のアクセントを、文章に自動で付けてくれる辞書ツールです。
みんなでアクセントを持ち寄って、**出典つき・承認制**で辞書を育てます。

> 「ジャパクセント」と読みます。Japan + Accent。それ以上でも以下でもありません。

---

## 1. すぐ使う（ログイン不要）

1. サイトを開く
2. 左の「入力」に文章を書く（例: `男の子が箸で飴を食べた。`）
3. 右の辞書に載っている語に、アクセントが自動で付いて「結果」に出ます

### 表示方式（上のボタン or `t` キーで切替）

| 方式 | 見た目 | 読み方 |
|---|---|---|
| **旧方式** | 高い音の上に線、下がる所にカギ（┐） | 線の上が高い |
| **新方式** | 下がる所に `＼` | `オトコ＼ノコ` = 「コ」の後で下がる |

- **漢字併記**: 結果の下に元の漢字を小さく出す
- **かな一致**: ひらがな・カタカナで書かれた語にも付ける
- 同じ読みで複数ある語（箸・橋・端 など）は、**点線の付いた語をクリック**すると候補が切り替わります
- 自分専用の辞書は「ローカル保存」でブラウザ内に作れます（他の人には見えません）

---

## 2. アクセントの書き方

下がる所に `／` を入れます（`/` でもOK）。**記号なしは平板型**です。

| 入力 | 意味 | 種類 |
|---|---|---|
| `ハ／シ` | 1音目の後で下がる | 頭高 |
| `オトコ／ノコ` | 3音目の後で下がる | 中高 |
| `ハシ／` | 最後の音の後で下がる | 尾高 |
| `サクラ` | 下がらない | 平板 |

ひらがなで打てば自動でカタカナになります。「ャュョ」は直前の文字とセットで1音です。

---

## 3. 辞書に追加したい（申請）

1. 右上「Googleログイン」
2. 辞書画面で `a`（新規）か `e`（選択中の語を修正）
3. 表記・アクセントを入れ、**出典を必ず書く**（例: `NHK日本語発音アクセント新辞典 2016 p.123`）
4. `Ctrl+Enter` で申請
5. 管理者が確認して、承認されると全員の辞書に載ります

**結果の確認**: 承認・却下されるとその場で画面に通知が出ます（却下のときは**理由つき**）。
あとからは `r`（または「申請」ボタン）で、自分の申請の状態と却下理由をいつでも見られます。メールは飛びません。

### 投稿のお願い
- 出典のない投稿、辞書や書籍の**丸写し**はお断りです。自分で確認した事実や、出典を示せるものだけにしてください。
- 投稿したアクセントのデータは **WTFPL**（何をしてもいい）で公開されます。
- 短時間に何度も申請すると、スパム扱いになります（→ 5）。

## 4. キーボード操作（Vim風）

| キー | 動作 |
|---|---|
| `j` / `k` | 辞書リストを下/上へ |
| `gg` / `G` | 先頭 / 末尾 |
| `a` | 新規追加（結果欄で語を選択してから押すと表記に入ります） |
| `e` | 選択中の語を編集 |
| `d` | 削除（`y` で確定）※自分のローカル辞書のみ。公開辞書は管理者だけ |
| `/` | 辞書内を検索（`Enter` でリストに戻る） |
| `i` | 文章入力欄へ |
| `t` | 旧方式 / 新方式 |
| `r` | 申請一覧（自分の申請の状況・却下理由） |
| `n` | お知らせ |
| `u` | ローカル編集の履歴（`Enter` で復元） |
| `:` | コマンドライン |
| `?` | ヘルプ |
| `Esc` | 閉じる / ノーマルモードへ |

モーダルの中では `Enter` で次の欄、`Ctrl+Enter` で確定、`Ctrl+S` でローカル保存。

隠しコマンドがいくつかあるかもしれません。

---

## 5. 荒らし対策（制限措置）

連続操作などのスパムを検知すると、次の順で制限されます。

**1分タイムアウト → 3分タイムアウト → キック → BAN → IP BAN**

- 制限中は画像つきの画面が出て、サイトを使えなくなります。
- 管理者はいつでも解除できます。間違いだと思ったら管理者に連絡してください。
- 管理者はスパム検知の対象外です。
- 24時間おとなしくしていれば、段階はリセットされます。
- IP BAN は誤爆（同じWi-Fiの別の人）の恐れがあるため、**管理者が確認して実行**します。

## 6. 集める情報（プライバシー）

Googleログインしたときに、アカウント名・メールアドレス・**IPアドレス**・ブラウザ情報・日時を記録します。
目的は荒らし・BAN回避の防止だけで、見られるのは管理者だけです。IPアドレスの取得のため ipify.org（失敗時は Cloudflare）へアクセスします。
ログインしなければ、閲覧もローカル保存も使えて、IPは集めません。サイト内の「規約」ボタンにも同じ内容があります。
